## 발표 진행과 답변 순서

15분 발표를 가정한 배분 예시다. 실제 시간은 발표자의 리허설로 확인한다.

| 구간 | 권장 시간 | 전달할 중심 내용 |
| --- | ---: | --- |
| 미션 1~4쪽 | 2분 | 표본·관찰 기간·거래/상품/고객의 분석 단위를 먼저 정의 |
| 미션 5~10쪽 | 3분 | 클래스 책임, 이미지 배열 축, 관측 상태와 대치의 대상·한계 |
| 미션 11~14쪽 | 2분 | IQR 보정 사본과 원금액 구분, 분포·상관·월별 결과 |
| 미션 15~19쪽 | 4분 | RFM 손계산, 동점·규칙 우선순위, 고객 기여와 실험 제안 |
| 미션 20~22쪽 | 2분 | 보너스, 검증 층위, 아직 측정하지 않은 성능·효과 |
| 전환·지연 여유 | 2분 | 화면 전환과 핵심 수치 재설명 |

첫 문장은 “선택 고객의 세 달 거래와 상품 이미지·텍스트를 연결하고, 원금액을 보존하면서 고객 행동을 설명하는 분석을 만들었습니다”로 시작한다. 본문에서는 결론을 먼저 말하고 코드·수식·실제 수치를 근거로 제시한다. 발표자 노트의 긴 문단은 설명 준비용이며 그대로 낭독하지 않는다.

질의응답에서는 질문을 해당 문항에 연결한 뒤 **짧은 답 → 구현 또는 손계산 근거 → 해석 한계** 순서로 답한다. 준비 우선순위는 3-1 IQR의 분포별 차이, 3-2 대치 전후 표본 구성, 3-3 구매일 기준 Frequency, 4-1 픽셀 버퍼와 전체 메모리 구분, 4-3 시간 분리 이후에도 남는 표본 선택 누수다. 캠페인 효과·모델 성능·병렬화 속도 개선은 실제로 측정하지 않았으므로 성과로 말하지 않는다.

## 설명과 근거의 범위

- 실제 수치는 [분석 집계](../results/analysis_aggregates.json), 원본 사진·실행 표는 [제출 노트북](../../notebooks/analysis_report.ipynb), 그림은 기존 필수 차트·보너스 결과를 사용한다.
- 이미지와 거래·고객의 분석 단위를 구분한다. F는 고유 구매일 수이며 IQR·결측 대치는 EDA 사본에 적용하고 RFM·월별 금액은 원값을 사용한다.
- 최신 자체 검증의 22테스트·13셀과 과거 독립 환경 재현의 20테스트·12셀을 구분한다. 8.67초와 이미지 계측값은 문서에 기록된 해당 PC·실험 조건의 관측값이다.
- 캠페인 성과·모델 학습·병렬 캐시 개선은 검증되지 않은 설계안이다. 코호트는 가입월 자료가 없어 첫 관찰 구매월로 계산했다. 미래 라벨 설명에는 전체 관찰 기간으로 고객을 뽑은 표본 선택의 한계도 포함한다.
- PPTX의 표·추가 차트·수식 텍스트는 편집 가능하다. 원본 실행 그림은 비율과 내용을 보존한 이미지다. PDF는 화면 열람용이며 상세 노트는 PPTX에서 읽는다.

## 재생성

원고는 [미션 설명](../../utils/mission_presentation_content.mjs)과 [평가 Q&A](../../utils/evaluation_qa_content.mjs), 작성·검증은 [공통 작성 도구](../../utils/build_split_presentations.mjs)에서 관리한다. 평가 원고는 기존 질문별 원고를 재사용하고 최신 증거를 보강한다. Windows의 PDF 변환은 [PowerPoint 변환 도구](../../utils/export_presentation_pdfs.ps1)를 호출하므로 Microsoft PowerPoint 설치가 필요하다. 최종 PDF 두 개는 PowerPoint로 변환한 뒤 전체 페이지를 이미지로 검토했다.

분석 의존성과 발표 작성 도구는 분리한다. 아래 경로는 이 PC의 번들 위치이며 다른 환경에서는 해당 런타임 위치로 바꾼다. 출력 파일을 덮어쓰지 않으므로 개정할 때 새 출력 폴더를 지정한다.

```powershell
$artifactNode = "C:/Users/4cat1/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe"
$artifactModules = "C:/Users/4cat1/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules"
$slideSkill = "C:/Users/4cat1/.codex/plugins/cache/openai-primary-runtime/presentations/26.1105.12137/skills/presentations"
$artifactPython = "C:/Users/4cat1/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe"
& $artifactNode utils/build_split_presentations.mjs --modules $artifactModules --skill-dir $slideSkill --python $artifactPython --output docs/presentation/revision
& $artifactNode utils/build_split_presentations.mjs --pdf-only true --modules $artifactModules --skill-dir $slideSkill --python $artifactPython --output docs/presentation/revision
```

슬라이드 PNG·페이지 매핑·PPTX 구조·글꼴·표·차트 검증 기록은 Git 제외 경로 `data/presentation-split-build/`에 저장한다. 원고 변경 후에는 수치와 그림, 발표자 노트와 전체 장의 가독성을 함께 검토한다.
