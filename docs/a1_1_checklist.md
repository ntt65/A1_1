# A1 1 이커머스 데이터 분석 작업 체크표

[미션 원문](a1_1_mission.md) · [기본 계획](a1_1_implementation_plan.md) · [상세 계획](a1_1_detailed_plan.md)

항목의 검증 조건을 충족하면 체크하고, 주요 수치나 노트북 위치를 아래 결과 기록표에 남긴다. 미완료 항목에는 관찰한 문제와 다음 확인 작업을 적는다. 항목 번호는 상세 계획과 같다.

## P0. 시작 전 실행 환경

- [x] **P0 실행 환경** · Python 3.11 가상환경에서 분석 패키지 4개가 로드되고, 노트북 커널이 같은 가상환경에서 실행된다. 사용한 버전을 기록했다.

## A. 데이터 선정과 검증

- [ ] **A1 데이터 채택** · 제공 샘플을 확인했다. H&M을 쓸 경우 비공개 Kaggle Notebook에서 표본만 만들고 로컬로 옮겼다. 표본 ZIP 용량과 코드·집계 결과의 공개 범위를 기록했다. `data/`가 Git에서 제외되고 추적 중인 데이터가 없다.
- [x] **A2 스키마** · 실제 파일명, 필수 열, 조인 키, 날짜·금액 변환 규칙, 채널 범위를 확정했다. ID의 선행 0이 보존된다.
- [x] **A3 관찰 범위** · 완전한 달 3개 이상과 표본 추출 전 마지막 유효 거래일을 기록했다. 표본을 사용했다면 시드·크기와 선택 고객의 기간 내 유효 거래가 모두 들어 있는지 확인했다.
- [x] **A4 데이터 기준** · 유효 거래 1,000건 이상, 분석용 열 8개 이상, 데이터 유형 3가지 이상을 확인했다. 실제 상품명과 이미지 배열을 연결했고 이미지 분석에 사용할 관측값과 읽기 성공률을 확인했다.

## B. 로드와 멀티모달 피처

- [ ] **B1 클래스** · `DataAnalyzer`의 필수 메서드 4개를 노트북에서 호출했다. 주요 파라미터는 인자로 전달되며, 입력 누락 시 오류가 원인을 표시한다.
- [ ] **B2 조인** · 거래와 상품을 다대일로 조인했다. 미매칭 건수를 기록했고, 조인 전후 거래 행 수와 유효 구매금액 합계가 일치한다.
- [ ] **B3 이미지** · 상품 이미지의 평균·표준편차를 NumPy 배치 연산으로 계산해 두 열로 추가했다. 읽기 성공, 누락, 손상, 크기 미달, 표본 미포함을 구분했다.
- [ ] **B4 피처 확인** · 상품명 `Blue cotton shirt`의 길이 17과 단어 수 3, 0과 1이 절반씩 들어 있는 이미지의 평균과 표준편차 0.5를 확인했다. 회색조·RGB·읽기 실패도 확인했다.

## C. 정제와 RFM

- [ ] **C1 유효 거래** · 정제·범위·표본 제외와 표본 거래의 합이 원본 행 수와 일치한다. 로컬 CSV 행 수를 추출 기록과 대조했고, 원래 금액과 동일 값의 유효 구매 행을 보존했다.
- [ ] **C2 결측치 대치** · 그룹 평균 대치를 적용했다. 대치 전후 결측 수와 방법별 대치 건수를 기록했고, 작은 입력에서 그룹 평균 `20`, 전체 평균 `30`, 기존 관측값 `50`을 확인했다.
- [ ] **C3 이상치** · IQR 경계와 탐지 수를 기록했다. 검증 입력에서 `100`만 탐지되는 경우와 정확히 경계인 값이 정상인 경우를 확인했다. 분석용 보정 후에도 RFM 입력 금액이 보존된다.
- [ ] **C4 RFM 계산** · 기준일과 Frequency 단위를 명시했다. 작은 입력에서 고객 A `0·2·60`, 고객 B `1·1·5`, Monetary 합계 `65`를 재현했다. 같은 지표값의 점수가 동일하고 입력 순서를 바꿔도 유지된다.
- [ ] **C5 세그먼트** · 분류 규칙과 우선순위를 기록했다. 유효 고객마다 그룹이 하나이며, 고객이 있는 그룹이 4개 이상이다.

## D. 분석 노트북

- [ ] **D1 기본 탐색** · `head()`, `info()`, `describe()`와 처리 전후 건수가 있으며, 수치 근거와 시사점을 설명했다.
- [ ] **D2 통계** · 평균·중앙값·표준편차·사분위수를 계산했다. 상관계수 2쌍 이상에 유효 표본 수, 수치 근거와 시사점이 있다.
- [ ] **D3 차트** · 히스토그램, IQR 전후 박스플롯, 막대그래프, 히트맵, 산점도, 월별 라인차트를 만들었다. 제목과 축 레이블이 있고 월별 합계가 유효 거래 합계와 일치한다.
- [ ] **D4 프로파일** · 세그먼트별 고객 수·비중, 대표 RFM 값, 구매금액 기여도를 비교했다. 고객 수와 구매금액 합계를 입력과 대조했다.
