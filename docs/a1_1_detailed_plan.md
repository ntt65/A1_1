# A1 1 이커머스 데이터 분석 상세 구현 계획

[미션 원문](a1_1_mission.md) · [기본 계획](a1_1_implementation_plan.md) · [작업 체크표](a1_1_checklist.md)

상품 이미지와 텍스트를 수치화하고, 구매 기록을 기준으로 단골 고객을 찾는다. 기존 `DataAnalyzer`와 노트북 목차를 바탕으로 구현한다. 현재 로컬 작업 폴더에는 분석용 데이터가 없으므로, 첫 작업은 실제 데이터로 스키마와 공개 조건을 확인하는 것이다.

| 단계 | 시간 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- |
| A. 데이터 선정과 검증 | 10시간 | 데이터 사용·공개 범위, 입력 열, 분석 기간과 표본 범위 확정 |
| B. 로드와 멀티모달 피처 | 10시간 | 실제 거래와 상품 조인, 실제 이미지와 텍스트 피처 생성 |

## A. 데이터 선정과 검증

### A1. 데이터 접근과 공개 범위 확인

H&M을 첫 후보로 두고, [기본 계획의 데이터 출처와 대회 규정](a1_1_implementation_plan.md#1-데이터-선정과-준비)을 기준으로 구매 CSV, 상품 CSV, 이미지에 접근할 수 있는지 확인한다. 필요한 파일과 다운로드 용량을 기록하고, GitHub에 올릴 코드와 집계 결과의 공개 범위를 확인한다. 원본과 제한이 있는 중간 산출물은 `data/` 아래에 보관하고 분석을 시작하기 전에 Git 제외 설정을 확인한다.

접근·용량·공개 조건으로 채택이 어렵다면 기본 계획의 UCI Online Retail과 Amazon Berkeley Objects 조합을 검토한다. 별도 데이터로 상품 피처와 RFM을 분석하는 구성이 미션에 허용되는지 확인한 후 전환한다. 이 경우 UCI의 `InvoiceNo`를 주문 ID로, `UnitPrice × Quantity`를 금액으로 사용하고 취소·반품은 양의 구매 집계와 분리한다. 상품 분석은 ABO의 자체 상품 ID와 이미지 연결을 사용한다.

### A2. 입력 구조 고정

H&M 채택 시 아래 경로와 열 이름을 기준으로 작업한다. 첫 샘플을 읽어 실제 파일명과 열 이름을 대조한 뒤 README에 확정값을 기록한다.

| 입력 | 로컬 경로 | 분석용 열과 단위 |
| --- | --- | --- |
| 구매 내역 | `data/raw/hm/transactions_train.csv` | 구매 상품 행 단위. `customer_id`, `article_id`, `order_date` (`t_dat`), `amount` (`price`), `sales_channel_id` |
| 상품 목록 | `data/raw/hm/articles.csv` | `article_id`별 한 행. `product_name` (`prod_name`), `category` (`product_type_name`) |
| 이미지 | `data/raw/hm/images/` | `article_id`로 찾은 파일. 읽기 상태와 분석 대상 여부를 기록 |

고객·상품·주문 ID는 문자열로 유지한다. 날짜는 일 단위 분석이 가능하게 변환하고, 금액은 유한한 수로 변환한다. 분석용 거래 테이블에는 위 거래 열 5개, 상품명과 카테고리, 이미지 처리 상태가 들어가도록 한다. 이미지 배열은 상품 단위 배치에서 처리하고, 계산한 피처를 상품 ID로 연결한다.

### A3. 관찰 기간과 표본 고정

1. 거래 범위에서 완전한 달 3개 이상을 연속으로 선택한다. 양끝 달의 수집 범위가 확인되지 않으면 제외한다. 시작일 포함, 종료일 제외 규칙을 적용하고 선택한 기간을 기록한다.
2. 해당 기간의 고객을 우선 모두 사용한다. 메모리나 실행 시간이 초과되면 기간 내 유효 고객 ID를 정렬한 뒤 고정 시드 `42`로 고객을 추출한다. 추출 고객의 기간 내 유효 거래를 전부 보존하고, 거래 CSV를 나눠 읽더라도 고객 선정이 앞부분 청크에 치우치지 않도록 한다.
3. 실제 이미지가 있는 상품을 먼저 소량 확인한다. 전체 대상 이미지 처리가 어려우면 상품 단위로 재현 가능한 표본 범위를 고정하고, 읽기 성공·파일 없음·손상·표본 미포함을 구분한다. 이미지 표본 선정은 RFM 고객·거래 표본과 분리한다.

### A4. 실데이터 채택 판정

정제 후 유효 거래 1,000건 이상, 분석용 테이블 8개 이상 열, 수치·범주·날짜 등 최소 3가지 유형을 확인한다. 실제 상품 이미지와 텍스트를 연결한 샘플도 확인한다. 초기 결과에 원본 기간, 최종 기간, 고객 수, 거래 수, 상품 수와 이미지 읽기 성공 수를 남긴다. 구매 금액의 화폐 단위가 확인되지 않으면 원본 단위로 보고한다.

## B. 로드와 멀티모달 피처

### B1. `DataAnalyzer` 입출력 연결

`src/pipeline.py`의 `DataAnalyzer.load_data()`와 `--data` CSV 로드 경로를 활용한다. 실제 분석에서 필요한 열과 ID 자료형을 명시하고, 필수 열이 빠졌거나 입력이 비었으면 경로 또는 누락 열을 오류에 표시한다. Jupyter 노트북에서는 같은 클래스 메서드를 호출한다. 관찰 기간, 시드, 데이터 경로 등 실험 설정은 노트북의 설정 셀 한 곳에 둔다.

### B2. 상품 조인과 분석 단위 분리

거래에서 상품으로 `article_id` 기준 다대일 왼쪽 조인을 한다. 상품 키가 중복되면 원인을 확인한 뒤 규칙을 기록하고, 매칭 여부를 집계한다. 조인 전후 거래 행 수와 유효 금액 합계를 대조한다. 구매와 월별 추세는 거래 단위, 이미지·텍스트 관계는 상품 단위, RFM은 고객 단위에서 계산한다.

### B3. 이미지 피처 연결

상품 ID별 이미지를 `matplotlib.image.imread()`로 한 번 읽는다. 회색조는 RGB 세 채널로 펼치고, 알파 채널이 있으면 RGB 세 채널을 사용한다. 픽셀은 0~1 범위로 맞추고, NumPy 인덱싱으로 기본 `32 × 32 × 3` 크기로 다운샘플링한다. 최소 크기 미달이나 읽기 실패는 건수를 기록하고 피처를 결측으로 둔다. 공통 크기 이미지를 배치로 쌓아 기존 `extract_image_features()`의 축 연산으로 이미지당 평균과 표준편차를 계산한다. 메모리가 부족하면 배치 크기를 줄인다.

### B4. 텍스트 피처와 입력 검증

`extract_text_features()`로 상품명 길이와 공백 기준 단어 수를 구한다. 누락 상품명을 빈 문자열로 처리하기 전에 원래 결측 수를 기록한다. 작은 입력에서 `"Blue cotton shirt"`의 길이 17과 단어 수 3을 확인한다. 픽셀 값의 절반이 0이고 절반이 1인 배열에서 이미지 평균과 표준편차가 각각 0.5인지 확인하고, 회색조·RGB·읽기 실패 이미지도 검증한다.

## C. 정제와 RFM 집계

### C1. 유효 거래 분리

거래의 제외 사유를 정하고 건수를 합산할 수 있게 한 행에 대표 사유 하나를 기록한다. 고객 ID 누락, 날짜 변환 실패, 금액 변환 실패 또는 0 이하, 관찰 기간 밖 거래, 표본 추출 대상이 아닌 고객의 거래를 구분한다. 동일 값의 H&M 구매 행은 유지한다. RFM 입력에는 구매금액 원값을 보존하고, 이미지나 상품 매칭 여부와 관계없이 유효 거래를 포함한다.

### C2. 그룹별 결측치 대치

`handle_missing_values()`의 그룹 평균을 지정한 수치 피처에만 적용한다. 예를 들어 분석용 이미지 평균 사본에 카테고리별 평균을 적용하고, 그룹 평균이 없으면 해당 피처의 전체 평균을 사용한다. 전체가 결측인 피처는 결측으로 두고 보고한다. 원본 이미지 피처와 기존 관측값은 보존한다. 그룹이 비어 있어도 관측값이 유지되는지와 대치 전후 결측 수를 확인한다. 실제 입력에 적용할 결측이 없으면 검증 입력의 시연을 실제 데이터 결과와 분리한다.

### C3. IQR 탐지와 분포 보정

`detect_outliers()`에서 Q1과 Q3, `IQR = Q3 − Q1`, 기본 임계 배수 `1.5`로 하한과 상한을 계산한다. 경계값은 포함하고 바깥 값만 표시한다. EDA용 사본의 값만 상하한으로 보정해 원본과 비교한다. 예를 들어 `[1, 2, 3, 4, 100]`에서 경계는 `−1`, `7`이고 `100`만 탐지된다. 분산이 없어 비교가 어려운 변수는 그 상태를 기록하고, 실제 비교에는 유효한 분포를 가진 수치 변수를 선택한다.

### C4. RFM 지표와 점수 산출

| 지표 | 집계 규칙 |
| --- | --- |
| `Recency` | 분석 표본에서 유효 거래의 최종 날짜와 고객 최종 구매일의 일수 차이. 기준일 구매는 0일 |
| `Frequency` | H&M은 고객별 고유 구매일 수. 주문 ID가 있는 입력에서는 고유 주문 수 |
| `Monetary` | 고객별 유효 구매금액 원값의 합계 |

R은 Recency 내림차순, F와 M은 각 지표 오름차순으로 평균 순위를 매긴다. 고객 수를 `n`이라 할 때 `(평균 순위 − 0.5) / n`을 계산한다. 이 값이 0.25 이하이면 1점, 0.50 이하이면 2점, 0.75 이하이면 3점, 그보다 크면 4점이다. 동일값은 같은 점수를 받고, 데이터가 한 값에 몰려 일부 점수가 비면 그 분포를 기록한다. 행 순서를 바꿔도 동일 고객의 점수가 같은지 확인한다.

집계 검증용으로 A 고객이 1월 1일에 `10`, `20`, 1월 3일에 `30`을 구매하고 B 고객이 1월 2일에 `5`를 구매한 입력을 사용한다. 1월 3일을 기준으로 A의 R·F·M은 `0·2·60`, B는 `1·1·5`다. 전체 고객의 Monetary 합계는 `65`다. 주문 모드에서는 같은 주문의 상품 행 여러 개가 한 주문으로 집계되는 경우도 확인한다.

### C5. 고객 세그먼트 분류

아래는 실데이터 검토 전의 초기 규칙이다. 위에서부터 처음 일치한 그룹에 배정한다. `R`, `F`, `M`은 점수이며 구매 횟수는 C4에서 정한 Frequency 원값이다.

| 우선순위 | 그룹 | 초기 조건 |
| --- | --- | --- |
| 1 | `VIP` | R·F·M이 모두 3점 이상이고 구매 횟수 2회 이상 |
| 2 | `Loyal` | R·F가 3점 이상이고 구매 횟수 2회 이상 |
| 3 | `New` | R이 3점 이상이고 관찰 기간 내 구매 횟수 1회 |
| 4 | `Churned` | R이 2점 이하인 이탈 위험 고객 |
| 5 | `Potential` | 위 조건에 해당하지 않는 고객 |

전체 유효 고객이 한 그룹에만 속하고, 고객이 있는 그룹이 최소 4개인지 확인한다. 그룹 수가 부족하면 관찰 기간과 표본 규모, 지표 분포와 점수 경계를 점검하고 변경 근거를 기록한다. `New`는 기간 내에 한 번 구매가 관측된 고객이며, `Churned`는 낮은 최근성을 기준으로 분류한다.

## D. 분석 노트북 작성

### D1. 데이터 탐색과 처리 과정 표시

`notebooks/analysis_report.ipynb`를 **설정 → 데이터 탐색 → 피처 생성 → 결측과 이상치 → 통계와 RFM → 차트와 해석** 순서로 실행할 수 있게 구성한다. `head()`, `info()`, `describe()`로 구조를 확인하고 정제 단계의 건수와 변화량을 출력한다. 공개용 결과의 예시 행은 이용 범위에 맞춰 집계 또는 가린 형태로 표시한다.

### D2. 요약 통계와 상관계수

`DataAnalyzer`에 요약 통계 메서드를 두고 평균, 중앙값, 표준편차와 사분위수를 출력한다. 상품 단위에서 관측 이미지의 평균과 표준편차, 고객 단위에서 Frequency와 Monetary의 피어슨 상관계수를 계산한다. 쌍별 유효 표본 수와 계수를 기록한다. 표본 부족이나 한쪽 지표의 분산 부족으로 계수를 해석하기 어려우면 유효한 다른 쌍을 사용한다. 탐색과 주요 통계 해석마다 **관측 수치 하나 이상과 시사점 한 문장 이상**을 붙인다.

### D3. 필수 차트 6종

| 차트 | 입력 단위와 축 | 확인할 내용 |
| --- | --- | --- |
| 히스토그램 | 거래. 금액 × 건수 | 집중 구간과 꼬리 |
| 박스플롯 | 거래. 보정 여부 × 금액 | 같은 값의 IQR 보정 전후를 동일 축으로 비교 |
| 막대그래프 | 고객. 세그먼트 × 고객 수 | 세그먼트 크기 |
| 히트맵 | 고객. RFM 변수 × RFM 변수 | 상관계수의 방향과 크기 |
| 산점도 | 상품. 관측 이미지 평균 × 관측 이미지 표준편차 | 이미지 특성의 분포와 관계 |
| 라인차트 | 월. 완전한 월 × 유효 구매금액 합계 | 선택 기간과 표본 안에서의 월별 변화 |

모든 차트에 제목, 축 레이블과 해당 단위를 표시한다. 이미지 산점도와 이미지 상관계수에는 관측 피처를 사용한다.

### D4. 세그먼트 프로파일 비교

세그먼트마다 고객 수와 비중, Recency와 Frequency 중앙값, 고객당 Monetary, 전체 구매금액 비중을 한 표에 표시한다. 고객 수 합계를 유효 고객 수와, 금액 합계를 RFM 입력 금액과 대조한다. 고객 구성과 구매금액 기여가 어떻게 다른지 수치로 설명한다.
